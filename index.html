apt.cartercole.net

An apt repository for the tools at github.com/CarterCole. Add it once; after that they install and upgrade like any other package.

Add the repository

On Debian 12 or newer, or Ubuntu 22.04 or newer. This one file holds the repository and its signing key:

sudo curl -fsSLo /etc/apt/sources.list.d/cartercole.sources https://apt.cartercole.net/cartercole.sources
sudo apt update

Install

Any of the packages below, by name:

sudo apt install bond kith

sudo apt upgrade picks up new releases. To remove the repository, delete /etc/apt/sources.list.d/cartercole.sources.
